# Margaret Nangorombi Mwangi — Portfolio

Professional portfolio covering research, monitoring and evaluation, data analysis, digital data collection, data quality, reporting and evidence generation.

## Website files
- `index.html` — website structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation, case-study filters and current footer year
- `margaret-profile.jpg` — profile photograph
- `Margaret-Nangorombi-Mwangi-CV..pdf` — curriculum vitae

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages
The site is designed for the root of this repository. In **Settings → Pages**, use **Deploy from a branch**, select `main` and `/(root)`.

## Notes
- Case studies are anonymised summaries; client-confidential information and unpublished datasets are not published.
- Experience, qualifications and achievement figures are based on the portfolio and CV information supplied.
- The capabilities section describes professional methods and tools; it does not imply that every listed tool has a separate public demo project.
